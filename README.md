# 贪吃蛇

一个无需安装依赖、可直接在浏览器中运行的贪吃蛇小游戏，也可以安装到手机主屏幕或打包为 Android 应用。

## 开始游玩

直接用浏览器打开 `index.html`。

## 手机游玩

项目带有离线缓存和主屏幕安装配置。将整个项目放到支持 HTTPS 的静态网站后，用 Android Chrome 或 iPhone Safari 打开，选择“安装应用”或“添加到主屏幕”。安装后可离线游玩。

## Android APK

Android Studio 工程在 `Android/` 文件夹。构建说明见 [Android/README.md](Android/README.md)。

## 操作

- 使用方向键或 `W`、`A`、`S`、`D` 控制移动
- 按空格暂停或继续
- 按 `R` 重新开始
- 手机和平板可使用画面下方的触控方向键

每吃到一个果实获得 10 分。最高纪录保存在当前浏览器中。
